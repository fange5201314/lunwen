| 能力链 | 使用资源 | 为什么与怎样连接 |
| --- | --- | --- |

| 任务空间 | Codeg、AionUi、PI-Desktop | 参考画布、分叉、预览；PI保留插件与执行端；不同时安装全部工作台 |

| 决策与接手 | DeepSeek Agent Notes、write-notes-like-deepseek | 设计候选、否决、取代与验证记录；每次接手先加载相关有效决定 |
| 研究任务 | Research Units/Harness | 参考Unit、Run、证据与人工检查点；增加学校开题和全文翻译任务契约 |
| 文献与全文 | Paper Search CLI、getbib、Docling | 检索元数据 → 真全文 → 对象结构 → 引用与章节；只有摘要不能翻译 |
| 全文翻译 | 段落翻译API、术语库、PDFMathTranslate可选 | 术语与对象级完整性是核心；PDF翻译不能单独满足原译文四文件 |
| 排版与审计 | OfficeCLI、thesis-docx、document-SKILLs | 制作与独立审计分开；最终Word/PDF逐页检查依赖真实模板与渲染后端 |
| 架构图与专业图 | Archify、Draw.io MCP | 本次Archify实际出图；后续图源绑定决策与方案，编辑图保留源文件 |
| API与连续性 | 现有CC-Switch、Octopus；AxonHub/GPT-Load对照 | 一份有限重试预算，保留真实错误；同能力渠道切换，断流片段不入成果 |
| 专业工程 | CAD-Agent-Hub、TIA Openness、CODESYS | Windows原生软件桥 + 会话锁 + 原生工程、实际编译/求解与论文证据 |
| 执行与工具 | Pi/现有CLI、GenericAgent、Hermes、FastMCP | runtime与工具能力可替换；工作站定义统一任务、产物、取消和恢复契约 |

知识管理资料中Obsidian、NotEMD、Nocturne、llm-wiki的启发用于“来源、项目隔离、版本和相关记忆”。首版用PostgreSQL和文件库实现所需索引；不强行让四个知识库同时成为事实源。论坛关于长任务、Skill服务封装、低成本执行与结果回填的方法转成能力自测、最小上下文、确定性检查与证据映射。

其余全量资源保留可搜索条目和分类。内容不足、图片缺失、原文没有接口或平台不适合的条目保持候选/资料状态；与首版无关的创作、账号工具和生活条目不虚构执行用途。

## 3. 模型API与依赖要求

| 需求 | 接入方式 | 缺失时的行为 |
| --- | --- | --- |
| 已有模型API渠道 | provider_alias / endpoint_ref / model_id；由服务端安全读取密钥 | 配置未就绪，不让正式制作派发；保留独立准备任务 |
| 同能力备用渠道 | 同一模型组 + 评测能力画像 + 一份请求总上限 | 没有备用时清楚显示；原渠道失败转人工，不保证永不中断 |
| 文献元数据与真全文来源 | Paper Search CLI所需来源与合法可获得PDF；检索日志入库 | 只有摘要不视作真全文，列缺口或待选择其他候选 |
| Python文档依赖 | Docling及选定OCR/渲染工具；模型下载路径按固定版本核对 | 不把工具未安装当成功解析；复杂页保持待检 |
| Office输出后端 | OfficeCLI与Word/LibreOffice；thesis-docx检查 | 输出前检查可用性；复杂公式模板实机对比 |
| Windows专业软件 | CAD/CAE/TIA/CODESYS实际版本、许可、工程目录与桥 | 只登记候选，不派发专业执行 |
| 持久服务 | PostgreSQL、对象文件库、主派发器、本机Worker | 队列与运行恢复需校验；API/GUI进程不假定永存 |
| 手机通知 | 一个明确渠道与接收配置，服务端凭据引用 | 未配置显示未就绪；不声称已发送或已送达 |

设计阶段不新增实际密钥，不要求你在聊天里发送凭据，不尝试使用未知 API 余额。检索/专业软件/通知的网络目标在选定实际接口后列出；没有据候选名称编造完整域名白名单。

## 5. 怎样打开和评估

下载完整ZIP，解压到同一目录。双击“可点击原型.html”用现代浏览器打开；此文件的数据全部内嵌，不需要npm或API。架构图、Excel、方案HTML为同目录关联文件，保持目录结构即可。

建议8分钟走查：确认示例方案 → 查看岗位与双轮讨论 → 写入决策板 → 推进阶段 → 注入业务失败 → 看其他项目继续 → 人工恢复 → 模拟API切换与全失败 → 推进至检查通过 → 预览并验收 → 导出评估JSON。

原型评分按钮保存本浏览器，可下载评估与操作JSON。重置演示保留评分。只有模拟状态，没有真实论文、软件工程或手机消息。ZIP不包含模型凭据。
