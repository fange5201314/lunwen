在本机从官方仓库取得该提交后，在本交付目录运行（ARCHIFY_SOURCE_ROOT改成你的源码路径）：

```bash
node "$ARCHIFY_SOURCE_ROOT/archify/bin/archify.mjs" finalize architecture \
  .archify/architecture-thesis-studio-20261009-120000/candidate.json \
  .archify/architecture-thesis-studio-20261009-120000/architecture.html \
  --quality showcase --json --out-dir research/local-archify-review
```

本次schema验证、HTML渲染与严格来源检查通过。云机系统Chromium禁止file URL导航，因此内置browser-check没通过；未修改浏览器管理策略。独立HTTP浏览器验证已完成，结果见research/final-browser-report.json。不要把内置最后一项写成通过。

## 原型和文档验证

- research/prototype-test-report.json：41项真实浏览器交互检查，0失败、0JavaScript异常。
- research/final-browser-report.json：附加协作图、恢复图、原型切图、静态SVG、PDF及文档图片验证。
- research/delivery-validation.json：28项数据、数量、引用、源文件、Excel、Word与任务Schema检查。

测试脚本使用Python Playwright和当前系统Chromium；每个浏览器脚本自己启动随机端口的本机HTTP服务器，仅供内部验证，不生成用户预览链接。用户本机Chromium路径不同时调整executable_path，或使用自己已有Playwright浏览器。docx、openpyxl、jsonschema用于文档和配置复核；它们不属于原型运行依赖。

图源为设计JSON，角色、节点、章节和成果源为config中的JSON；它们不是已执行工程日志。原型数据全部内嵌，可离线访问，不读取模型凭据。
