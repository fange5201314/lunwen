5. 怎样打开和评估

下载完整ZIP，解压到同一目录。双击“可点击原型.html”用现代浏览器打开；此文件的数据全部内嵌，不需要npm或API。架构图、Excel、方案HTML为同目录关联文件，保持目录结构即可。

建议8分钟走查：确认示例方案 → 查看岗位与双轮讨论 → 写入决策板 → 推进阶段 → 注入业务失败 → 看其他项目继续 → 人工恢复 → 模拟API切换与全失败 → 推进至检查通过 → 预览并验收 → 导出评估JSON。

原型评分按钮保存本浏览器，可下载评估与操作JSON。重置演示保留评分。只有模拟状态，没有真实论文、软件工程或手机消息。ZIP不包含模型凭据。
